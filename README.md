### MAST Formative Part 2

A mobile application built using **React Native**, **TypeScript**, and **Expo SDK 57**. The application allows users to view a curated food menu, filter items by courses using custom badge components, and add new custom culinary dishes dynamically to the manager layout. 

### 📱 Features

* **Interactive Menu Screen (MenuListScreen.tsx):** Displays a scrollable feed of available culinary offerings utilizing modular components.
* **Add Dish Portal (AddDishScreen.tsx):** A dynamic form wrapper designed to allow entry, structural management, and instantiation of new recipe elements.
* **Custom Course Badges (CourseBadge.tsx):** Tailored tag selectors allowing fluid structural categorization (e.g., Starters, Mains, Desserts).
* **Component-Driven Architecture (MenuItemCard.tsx):** Clean modular encapsulation of menu item visualizations for maximum visual performance.

### 🛠 Tech Stack & Dependencies

* **Framework:** React Native (Managed Workflow via Expo CLI)
* **SDK Baseline:** Expo SDK 57
* **Language Variant:** TypeScript (Strict Type Checking)
* **Design Engine:** Native Styling Engine & Vector Icons
